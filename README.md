# Ollyo Assignment Task

This is a frontend development assignment completed as part of an application process. The task was to convert a Figma design into a responsive, pixel-perfect webpage using modern web technologies.

## 🛠️ Built With

- **html** – html using for making document struct
- **css** – styleing the document elements
- **javascript** – adding some navigation interactivity

## 📐 Features

- Fully responsive layout (Mobile, Tablet, and Desktop)
- Pixel-perfect implementation from Figma design
- Clean, semantic HTML structure
- Smooth interactions and hover effects
- Modern and optimized frontend architecture



## 📁 Getting Started

To run this project locally:

1. Clone the repo  
   ```bash
   git clone https://github.com/mdemong87/ollyo-task.git


2. Navigate to the project folder

   ```bash
   cd ollyo-task


3. Install dependencies

   ```bash
   npm install

4. Run the development server

   ```bash
   npm run dev


5. Open in your browser at http://localhost:3000
